🌊 CurrencyWave — Smart Currency Dashboard

A modern, interactive, and responsive currency dashboard built with React.js.

CurrencyWave provides a clean and intuitive interface for exploring currency rates, converting currencies, viewing market charts, and managing favorite currencies. The project combines modern UI design, smooth animations, and responsive layouts to create an engaging dashboard experience.

✨ Features

- 📊 Interactive currency dashboard
- 💱 Currency conversion interface
- 📈 Currency market charts
- ⭐ Favorite currencies section
- 🌍 Support for multiple currencies, including USD, EUR, GBP, JPY, CAD, AUD, CHF, and AFN
- 🧭 Sidebar navigation
- 🌙 Dark and light themes
- 🎬 Smooth animations and transitions
- 📱 Responsive design for desktop, tablet, and mobile
- ⚙️ Organized sections for rates, conversion, charts, favorites, transactions, news, and settings

🛠️ Technologies Used

- React.js
- JavaScript (ES6+)
- Tailwind CSS
- Motion
- Lucide React
- Vite
- npm

🚀 Getting Started

Follow the instructions below to run the project on your local machine.

Prerequisites

Before starting, make sure you have installed:

- "Node.js" (https://nodejs.org/)
- npm (included with Node.js)

1. Download the Project

Download the ZIP file from this repository and extract it to your preferred location.

Alternatively, clone the repository:

git clone https://github.com/habibi80947591-debug/yalda-habibi-dashboard.git

2. Open the Project Folder

Open the extracted project folder in Visual Studio Code or your preferred code editor.

Open the terminal inside the project folder, where the "package.json" file is located.

3. Install Dependencies

Run the following command to install the required packages:

npm install

Important: The "node_modules" folder is not included in the ZIP file to reduce its size. Running "npm install" automatically downloads and installs the dependencies listed in "package.json".

4. Start the Development Server

After the installation is complete, run:

npm run dev

5. Open the Website

The terminal will display a local development URL, usually:

http://localhost:5173

Open this URL in your browser to explore CurrencyWave.

🏗️ Production Build

To create a production-ready build, run:

npm run build

To preview the production build locally, run:

npm run preview
